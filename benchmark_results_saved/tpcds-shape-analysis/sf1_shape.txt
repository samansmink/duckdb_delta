# Analysis

## Pyspark written parquet is slow on Q16
Firstly it's interesting to note that Pyspark writes exactly the same to delta as parquet. Which is unexpected because we see a huge difference in
performance for TPC-DS Q16: running this query on pyspark parquet is almost an order of magnitude slower. This seems to suggests that DuckDB has to
read a lot of parquet file metadata for that query making it a lot slower.

## Delta-RS written delta tables are slow
Interestingly, the Delta-RS tables have smaller row group size than the pyspark written table (around half the size) would this explain the fact that
the delta-rs tables are much (2x) slower than the pyspark ones? This difference could also be explained by the fact that the pyspark tables use different
encodings?
